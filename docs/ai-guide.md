# 캘리버 EPUB 변환용 워드 원고 정리 지침 (AI 작업용)

이 문서는 AI에게 주는 작업 지침입니다.
사용자가 첨부한 원고를 아래 규칙대로 정리해서 **워드(.docx) 파일**로 만들어 주세요.
이 파일은 이후 캘리버(Calibre)로 EPUB 전자책으로 변환되어 국내 서점(교보문고, 예스24, 알라딘, 유페이퍼 등)에 등록됩니다.

---

## 1. 절대 규칙 - 원고 내용

- 원고의 문장을 **바꾸거나, 요약하거나, 빼지 마세요.** 한 글자도 고치지 않고 그대로 옮깁니다.
- 맞춤법·오타가 보여도 직접 고치지 말고, 작업이 끝난 뒤 **목록으로만** 알려주세요.
- 원고가 길어서 한 번에 처리하면 내용이 빠질 위험이 있으면, **장별로 나눠서** 처리하고 사용자에게 다음 장을 요청하세요.

## 2. 제목 스타일 (목차가 여기서 만들어집니다)

워드 기본 스타일 이름을 그대로 씁니다.

| 대상 | 스타일 |
|------|--------|
| 부 제목, 장(챕터) 제목 | 제목 1 (Heading 1) |
| 장 안의 절 제목 | 제목 2 (Heading 2) |
| 목차, 저자 소개, 프롤로그, 에필로그, 맺음말 등의 제목 | 제목 2 (Heading 2) |

- 원고 앞쪽의 **목차 페이지**는 "목차"라는 제목 글자에만 제목 2를 넣습니다. **목차 항목들에는 제목 스타일을 넣지 마세요.** 넣으면 전자책 목차가 두 벌 생깁니다.
- 제목이 아닌 문단(강조 문장, 인용문 등)에는 제목 스타일을 넣지 마세요.
- 제목은 글자 크기만 키운 본문이 아니라 반드시 **스타일**로 지정해야 합니다.

## 3. 글자·줄간격

| 항목 | 값 |
|------|-----|
| 본문 줄 간격 | 1.5 (배수) |
| 본문 글자 크기 | 11~12pt |
| 제목 1 | 20pt 이상 |
| 제목 2 | 15pt 이상 |

- 한글 글꼴을 지정할 때는 **동아시아 글꼴(eastAsia)까지** 지정하세요. 영문 글꼴만 지정하면 한글이 바탕체로 나옵니다.
- 문단에 직접 박힌 글자 크기·글꼴 서식이 스타일을 덮어쓰고 있으면 걷어내서 스타일이 적용되게 하세요.

## 4. 하지 말 것

- **워드 자동 번호 목록을 쓰지 마세요.** "1. 2. 3."은 글자로 직접 입력합니다. (자동 번호는 EPUB 검사 오류의 원인)
- 머리글·바닥글·쪽 번호를 넣지 마세요.
- 글꼴 파일을 문서에 포함(embed)하지 마세요.
- Enter를 여러 번 쳐서 페이지를 넘기지 마세요. 빈 문단을 연달아 만들지 마세요.

## 5. 페이지 나누기

- 첫 페이지에 **표지 이미지**를 넣고, 바로 뒤에 페이지 나누기를 넣습니다. (표지 이미지가 없으면 비워두고 알려주세요)
- 각 **제목 1** 앞, 그리고 목차·저자 소개·프롤로그·에필로그 앞에 페이지 나누기를 넣습니다.
- 제목 뒤, 박스(표) 앞뒤에는 빈 줄 하나 정도의 간격을 둡니다.

## 6. 사진

- 사진은 **"텍스트 줄 안"(인라인)**으로 넣습니다. 떠 있는 개체(텍스트 배치, 앵커)로 넣으면 휴대폰에서 잘립니다.
- 가로 **9cm**, 가운데 정렬.
- 사진 설명(캡션)이 있으면 사진 바로 아래 문단으로 둡니다.

## 7. 박스 디자인 (선택)

TIP·주의·핵심 정리 같은 박스는 **1행 1열 표**로 만들고 배경색을 넣습니다. 도형이나 텍스트 상자는 쓰지 마세요 (전자책에서 사라집니다).

---

## 8. 작업이 끝나면 아래를 보고해 주세요

1. **제목 대조**: 원고의 목차 페이지 항목과, 제목 1·제목 2로 지정한 제목 목록을 나란히 비교한 결과. 빠지거나 다른 제목이 있으면 표시
2. **분량 비교**: 원고 원본과 정리본의 본문 글자 수 (거의 같아야 합니다)
3. **사진 개수**: 원본과 정리본
4. **오타 의심 목록**: 고치지 않고 위치만

사용자는 워드에서 **보기 → 탐색 창**을 켜서 목차가 제대로 잡혔는지 확인합니다.
