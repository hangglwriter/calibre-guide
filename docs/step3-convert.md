# 3단계. 캘리버로 변환하기

> 설정은 4개만 바꾸면 됩니다. 나머지는 전부 기본값!

## 3-1. 워드 파일 불러오기

1. 캘리버 실행
2. 왼쪽 상단 **"책 추가하기"** 클릭
3. 워드(.docx) 파일 선택 → 열기
4. 목록에 책이 추가됨

## 3-2. 변환 시작

1. 추가된 책을 클릭해서 선택
2. 상단 **"책 변환하기"** 클릭
3. 오른쪽 상단 **"출력 형식"**이 **EPUB**인지 확인

## 3-3. 변환 설정

왼쪽 메뉴를 하나씩 살펴보겠습니다. **대부분 기본값 그대로** 두면 됩니다.

### 모양과 스타일 > 글꼴 탭 ✏️ 바꿔야 함

![글꼴 설정](images/step3-font.png)

한글은 줄간격이 넓어야 읽기 편합니다. 120%면 너무 빽빽해 보입니다.

나머지(글꼴 크기, 글꼴 모음 포함 등)는 건드리지 않아도 됩니다.

![텍스트 설정](images/step3-text.png)

### 모양과 스타일 > 배치 탭 ⏭️ 기본값

### 모양과 스타일 > 스타일링 탭 ⚠️ 사진 많은 책만

<div class="tip-box">
💡 <b>글이 대부분인 책이라면 여기는 건너뛰세요.</b> 비어있는 상태 그대로 OK입니다.<br>
<b>사진이나 화면 캡처가 많은 책</b>만 아래를 따라 하시면 됩니다.
</div>

사진이 많은 책은 **스마트폰에서 사진 오른쪽이 잘려 보이는** 일이 생깁니다.

![사진 잘림 비교](images/step3-image-crop-compare.png)
*실제로 같은 책을 스마트폰 크기 화면에서 열어본 모습입니다. 왼쪽은 노트북 사진의 오른쪽이 통째로 잘려 나갔습니다.*

**왜 이런 일이 생기냐면**, 워드는 **종이(A4)를 기준으로 만든 문서**라서 사진 크기가 **"가로 15.9cm"처럼 딱 정해진 값**으로 들어갑니다.
그런데 전자책은 종이가 없습니다. 독자가 폰으로 볼지 태블릿으로 볼지 모르는데, **"15.9cm로 그려라"**는 지시만 그대로 넘어옵니다.
**내 컴퓨터 화면은 넓어서 멀쩡해 보이지만**, 화면이 좁은 스마트폰에서는 그만큼이 안 들어가서 밖으로 밀려납니다.

아래 **두 가지를 다** 해주시면 **"화면 크기를 넘지 마라"**는 지시로 바뀌어서, 사진이 화면에 맞춰 알아서 줄어듭니다.

![스타일링 설정](images/step3-styling.png)
*이 화면입니다. 위쪽에 **추가 CSS** 칸, 아래쪽에 **스타일 정보 필터링**이 있습니다.*

**① 위쪽 "추가 CSS" 칸에 아래 글자를 그대로 복사해서 붙여넣기**

```
img{max-width:100%;height:auto;display:block;margin:1em auto;}
```

<div class="tip-box">
💡 무슨 뜻인지 몰라도 괜찮습니다. <b>"사진을 화면 크기에 맞춰라"</b>는 뜻입니다. 그대로 붙여넣기만 하세요.
</div>

**② 아래쪽 "스타일 정보 필터링"에서 세 가지**

| 화면에 있는 이름 | 할 것 | 왜 |
|------|------|------|
| **글꼴** | 네모 칸에 체크 | 워드 글꼴 지정을 지웁니다 (독자 뷰어 글꼴로 보이게) |
| **부동요소** | 네모 칸에 체크 | 사진 옆으로 글자가 끼어드는 것을 막습니다 |
| **이 외의 CSS 속성** | 칸에 `width,height` 입력 | 워드에서 정해져 온 사진 크기를 지웁니다 |

<div class="warning-box">
⚠️ <b>①만 하면 안 됩니다.</b><br>
워드에서 정해져 온 사진 크기가 그대로 남아 있어서, 하나만 해서는 잘림이 다 없어지지 않습니다.<br>
<b>①과 ②를 꼭 같이</b> 해주세요.
</div>

<div class="tip-box">
💡 <b>이미 EPUB을 만들어 두셨다면</b><br><br>
이 설정은 <b>변환할 때 적용되는 것</b>이라, 만들어 둔 EPUB 파일은 저절로 고쳐지지 않습니다.<br>
<b>워드 파일에서 다시 한 번 변환</b>해 주세요. 원고를 고칠 필요는 없고, 위 설정만 넣고 변환 버튼을 한 번 더 누르시면 됩니다.
</div>

**제대로 됐는지 확인하는 법**

만든 EPUB을 **카카오톡으로 나에게 보내서 스마트폰에서 열어보세요.** (교보문고나 예스24 앱에 파일을 넣어서 보시면 됩니다.)

| 이렇게 보이면 | 판정 |
|------|------|
| 사진 **양쪽 끝이 다 보이고**, 화면 가운데에 놓임 | ⭕ 제대로 됐습니다 |
| 사진 **오른쪽이 잘려서** 안 보임 | ❌ 설정이 빠졌습니다. ①②를 다시 확인하고 재변환하세요 |

<div class="warning-box">
⚠️ <b>PC에서만 보고 넘어가지 마세요.</b><br>
PC 화면은 넓어서 <b>설정을 안 해도 멀쩡하게 보입니다.</b> 잘림은 화면이 좁은 스마트폰에서만 드러납니다.
</div>

## 3-4. 변환 실행

**"확인"** 버튼을 클릭하면 변환이 시작됩니다.

목차 세부조정을 체크했으면 아래와 같은 **목차 편집 창**이 뜹니다.

![목차 편집 화면](images/step3-toc-edit.png)

워드에서 제목 스타일을 잘 잡았으면 **목차가 자동으로 잡혀 있습니다**.

### 목차가 잘 잡혔을 때

- 녹색 체크(✅) = 정상적으로 연결된 항목
- ▶ 삼각형 클릭하면 하위 목차(소제목)가 펼쳐짐
- 그대로 **"확인"** 클릭

### 목차가 안 잡혔을 때

오른쪽 버튼 활용:
- **"모든 표제에서 목차 생성"**: 제목 태그 기반으로 다시 생성
- **"주 표제에서 목차 생성"**: 큰 제목만 가져오기

### 목차 수동 편집

- **더블클릭**: 항목 이름 수정
- **▲▼ 화살표**: 순서 변경
- **◀▶ 화살표**: 레벨 올리기/내리기
