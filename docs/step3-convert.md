# 3단계. 캘리버로 변환하기

> 설정은 4개만 바꾸면 됩니다. 나머지는 전부 기본값!

## 3-1. 워드 파일 불러오기

1. 캘리버 실행
2. 왼쪽 상단 **"책 추가하기"** 클릭
3. 워드(.docx) 파일 선택 → 열기
4. 목록에 책이 추가됨

## 3-2. 변환 시작

1. 추가된 책을 클릭해서 선택
2. 상단 **"책 변환하기"** 클릭
3. 오른쪽 상단 **"출력 형식"**이 **EPUB**인지 확인

## 3-3. 변환 설정

왼쪽 메뉴를 하나씩 살펴보겠습니다. **대부분 기본값 그대로** 두면 됩니다.

---

### 메타데이터 ✏️ 바꿔야 함

![메타데이터 설정](images/step3-metadata.png)

바꿀 것:
- **제목**: 책 제목 입력
- **저자**: 저자 이름 입력
- **설명란**: "generated by python-docx" 같은 자동 생성 문구가 있으면 삭제

<div class="tip-box">
💡 <b>참고</b><br>
출판사, 태그 등은 선택사항입니다. 비워둬도 됩니다.
</div>

---

### 모양과 스타일 > 글꼴 탭 ⏭️ 기본값

![글꼴 설정](images/step3-font.png)

건드릴 것 없음. **"최소 줄 높이"는 120% 기본값 그대로** 둡니다.

줄간격은 1단계에서 워드에 이미 넣었기 때문에 여기서 다시 손댈 필요가 없습니다.

---

### 모양과 스타일 > 텍스트 탭 ⏭️ 기본값

![텍스트 설정](images/step3-text.png)

건드릴 것 없음. 기본값 그대로 넘어갑니다.

---

### 모양과 스타일 > 배치 탭 ⏭️ 기본값

![배치 설정](images/step3-layout.png)

건드릴 것 없음. 들여쓰기 1.5em, 줄 크기 0.5em 기본값 OK.

---

### 모양과 스타일 > 스타일링 탭 ⏭️ 기본값

![스타일링 설정](images/step3-styling.png)

추가 CSS 비어있는 상태 그대로 OK. 워드 원본 스타일이 유지됩니다.

---

### 합리적 추측에 의한(Heuristic) 처리 ⏭️ 기본값

![Heuristic 설정](images/step3-heuristic.png)

맨 위 체크박스가 꺼져있으면 OK. 워드에서 제목 스타일을 잘 잡았으면 추측 기능이 필요 없습니다.

---

### 페이지 설정 ⏭️ 기본값

![페이지 설정](images/step3-page.png)

출력/입력 프로필 모두 **"Default profile"** 그대로.

한국 서점(교보/리디/밀리)은 범용 뷰어를 쓰므로 Default가 맞습니다.

---

### 구조 탐지 ⏭️ 기본값

![구조 탐지](images/step3-structure.png)

챕터 감지, 페이지 나누기 모두 기본값 그대로 OK.

---

### 목차 ✏️ 바꿔야 함

**변경 전:**

![목차 설정 - 변경 전](images/step3-toc-before.png)

**변경 후:**

![목차 설정 - 변경 후](images/step3-toc-after.png)

바꿀 것:
- **"자동 생성된 목차를 강제로 사용"** 체크 ON
- **"변환이 완료된 후 수동으로 목차 세부조정"** 체크 ON

<div class="tip-box">
💡 <b>왜 체크하나요?</b><br>
- "강제로 사용": 워드 원본에 목차가 없어도 제목 스타일 기반으로 자동 생성<br>
- "수동 세부조정": 변환 후 목차를 직접 확인하고 수정할 수 있는 편집 창이 뜸
</div>

---

### EPUB 출력 ✏️ 바꿔야 함

![EPUB 출력 설정](images/step3-epub-output.png)

바꿀 것:
- **"SVG 표지 없음"** 체크 ON

체크하지 않으면 표지 그림이 SVG라는 형식으로 한 번 감싸져 들어갑니다.
이걸 제대로 읽지 못하는 뷰어(교보 등)에서는 표지가 잘리거나 빈 화면으로 나옵니다.

<div class="tip-box">
💡 <b>참고</b><br>
바로 옆의 "표지 종횡비 보존"은 SVG를 쓸 때만 필요한 항목이라 체크하지 않아도 됩니다.<br>
"EPUB 버전"도 기본값 2 그대로 두면 됩니다. (한국 서점은 EPUB 2를 검사합니다)
</div>

<div class="warning-box">
⚠️ <b>변환 전에 체크해야 합니다</b><br>
이미 만들어진 EPUB에는 적용되지 않습니다.<br>
완성된 책을 고치려고 다시 변환하면 목차 편집 같은 손본 내용이 사라지니 주의하세요.
</div>

## 3-4. 변환 실행

**"확인"** 버튼을 클릭하면 변환이 시작됩니다.

목차 세부조정을 체크했으면 아래와 같은 **목차 편집 창**이 뜹니다.

![목차 편집 화면](images/step3-toc-edit.png)

워드에서 제목 스타일을 잘 잡았으면 **목차가 자동으로 잡혀 있습니다**.

### 목차가 잘 잡혔을 때

- 녹색 체크(✅) = 정상적으로 연결된 항목
- ▶ 삼각형 클릭하면 하위 목차(소제목)가 펼쳐짐
- 그대로 **"확인"** 클릭

### 소제목이 빠졌거나 목차가 안 잡혔을 때

워드 탐색 창에 보이던 제목(제목 1, 제목 2)이 **모두** 있는지 확인하세요. 제목에 "Chapter 1"처럼 영어가 들어 있으면 캘리버가 그 제목만 목차로 잡고 소제목을 빼는 경우가 있습니다.


오른쪽 버튼 활용:
- **"모든 표제에서 목차 생성"**: 제목 태그 기반으로 다시 생성
- **"주 표제에서 목차 생성"**: 큰 제목만 가져오기

### 목차 수동 편집

- **더블클릭**: 항목 이름 수정
- **▲▼ 화살표**: 순서 변경
- **◀▶ 화살표**: 레벨 올리기/내리기

## 설정 요약

전체 메뉴 중 **바꾼 건 딱 4개**:

| 메뉴 | 변경 사항 |
|------|----------|
| 메타데이터 | 제목/저자 입력, 설명란 정리 |
| 목차 | "자동 생성된 목차를 강제로 사용" **체크** |
| 목차 | "변환 후 수동으로 목차 세부조정" **체크** |
| EPUB 출력 | "SVG 표지 없음" **체크** |
